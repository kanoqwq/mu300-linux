# 主页卡槽选择与 USB 链路速率（2026-11-04）

## 行为

- 主页查看卡槽放在 hero 的“已运行”右侧；宽度不大于 600px 时放在 hero
  右上角。位置属于卡片，不依赖主题页头，不拖动、不全局悬浮。
- 其他页面保留原有整行折叠选择器。选择仍仅改变查看／控制对象，不切换
  上网卡或射频；E5 自有的跟随上网卡变化逻辑保留。
- 设备管理 → USB 角色增加“USB 链路速率”，带中／英／土翻译。设备模式
  读取选定 UDC 的 current_speed 和状态，主机模式读取同一控制器第一跳外设
  的 speed；不使用 maximum_speed、根 Hub 能力、其他控制器或下游子设备。
  双总线扩展坞可同时显示 480 Mbit/s 与 5 Gbit/s；SuperSpeedPlus 不猜测
  实际 lane 速率。无链路／读取不可用分别显示，不显示旧速率。
- 只在现有状态读取／刷新时查询，无新增常驻进程或周期任务，不写 USB 角色、
  充电配置、分区、NV 或 IMEI。E5 继续使用自己的 Python USB 适配器和
  usb_role_policy，MU300 继续使用原有 shell 适配器；主机＋外部供电控制不变。

## 构建与验证

公共 helper 为 luci 插件 root/usr/libexec/unisoc-modem/usb-link.uc，沿既有
插件 root／htdocs 复制及 Makefile 安装路径收录，不依赖实机文件。
E5 正式根审计新增此文件；U30 Pro 的目标根校验同时核对 helper 和 home.js。

MU300、E5 各 60 组浏览器检查覆盖官方主题／Aurora、明暗、中英土、
320–1920px、弹层边界、Esc、重复挂载清理、查看卡槽不改数据卡；E5 另测
跟随数据卡变化。真实目标 ucode 的 8 个合成 sysfs 场景覆盖不同速率、
断开、暂停、缺失／歧义 UDC、DWC3/MUSB 控制器定位、外供电策略路径、
不相关控制器、下游慢设备与双总线扩展坞。既有 USB 角色与页面回归通过。

U30 Pro 已热部署，并在实际网页桌面和移动尺寸核对布局，USB 设备链路
回读为 high-speed／configured（480 Mbit/s）。未切换实物主机／扩展坞复测；
MU300 与 E5 本轮为源码和离线回归，不等同各机型实物验收。打包按用户要求暂停。
