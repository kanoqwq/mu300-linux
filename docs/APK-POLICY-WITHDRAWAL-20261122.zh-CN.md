# 撤回自编内核 APK 身份迁移（2026-11-22）

## 最终范围

原问题是 Pro 附加软件源的依赖冲突，移除冲突源即可处理。不继续将这个
问题扩大为三个仓库的内核 APK 身份迁移，也不以尚未证实的 apk upgrade
启动故障作为依据。内核版本和已编译驱动没有因此变回 OpenWrt armsr 内核。

- MU300、Pro、E5 的组包入口不再重写 kernel/kmod 数据库，不再生成能力
  元包或附加自编内核版本锁；移除对应的主机生成器和旧测试。
- 保留原基础镜像的包记录策略、原模块加载机制、真实 Image/模块配套
  校验，以及 NFC、灯、Wi-Fi、充电等其他已完成修复。
- Pro 冲突软件源的移除保留。不添加插件专用内核配置，不关闭 APK 或
  内核模块自身的兼容检查。
- 共享 installer 固定到已审查的本地提交
  `1dbb1516024fdb45d9677822e6a47381c6ba3360`。只在更新目标恢复为基础
  包记录时，清理旧版本由我们自动生成、且精确依赖原生成 kernel 版本
  的能力元记录和 world 约束。不删除实际驱动文件或用户额外安装的包。
- world 合并统一识别 @软件源标签，避免遗留已撤回元记录的约束。
