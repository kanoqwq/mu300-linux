# 软件流量卸载开关

设备管理的“网络性能”卡片在 TCP 拥塞控制（BBR/CUBIC）下方增加“软件流量卸载”开关。
使用现有主题的开关样式，支持中文、英文、土耳其文；只读用户可查看，不能修改。

开关读取并仅修改防火墙 defaults 节的 `flow_offloading`，不创建另一套配置、
不强制改变默认值，不修改 BBR、网络接口、APN、射频或硬件卸载选择。
点击后保存 UCI 并重载 fw4，无需重启。状态独立加载，无定时轮询或额外常驻服务。
防火墙已有待应用的修改时先提示用户处理，不顺带提交其他未保存设置。

固定 TTL 的 netdev egress 规则可以继续与软件卸载同时使用。
操作与原 TTL 引擎共用互斥锁；只移除旧 TTL 版本对软件卸载的恢复记录，
保留硬件卸载恢复记录，避免用户关闭软件卸载后又被 TTL 关闭流程重新打开。
提交或防火墙重载失败会恢复原配置及 TTL 记录，并明确反馈恢复是否成功。

实现沿用 `unisoc-network-performance` RPC，读写 ACL 分离，写入仅接受 Boolean。
新 JS 和 ucode 文件由已有 LuCI 包的 htdocs/root 全目录安装和固件组装路径纳入，
不增加安装器、内核或设备型号分支。UCI/fs/fw4/flock 均为现有依赖。

离线回归使用真实 ARM64 ucode/UCI、隔离配置和无网络容器中的 fw4 替身，
覆盖开关、持久化、非法输入、待应用配置、失败恢复、TTL 标记和互斥；
另检查三种语言、明暗主题、320/390/1280 像素布局、加载/保存状态和只读权限。
原 TTL 回归保持通过。本轮没有重编固件、打包或部署到实机，不能据此声称
已验证实机吞吐或运行中的流量卸载命中。
