# U30 Air 开机后充电灯未进入呼吸模式

用户反馈开启插电自启动后，部分启动的电池灯在充电时不呼吸。本轮检查源码，
没有连接或部署 U30 Air；此前连接的 U30 Pro 不用于替代该机型硬件验证。

## 已确认的驱动缺陷

`upstream/port/drivers/leds/leds-sc27xx-bltc.c` 的常亮回调设置 `RUN|TYPE`，
呼吸回调却只设置 `RUN`，不会清除常亮的 `TYPE`。因此起始状态不同会产生
不同结果：已处于常亮模式时，即使写入了呼吸曲线，也会保留常亮模式。
启动指示与充电指示的交接可以经过这条路径；用户该次启动的具体状态仍待实测。

修正仅扩大呼吸回调的控制位掩码，在同一次 regmap 更新中清除所选通道的
`TYPE` 并设置 `RUN`，不改变其他灯、曲线、亮度、充电状态、电源策略或启动顺序。
用户态不新增灯效线程、轮询、固定延时或补写循环。

常亮切呼吸仍残留 `TYPE`，修正后通过三通道、每通道 1～255 亮度、重复设置、
满电常亮、关闭、其他通道保护、六处写入失败和无效曲线长度检查。
