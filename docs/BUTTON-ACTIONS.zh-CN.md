# 实体按键

单击固定执行原有动作，不允许配置，也不等待双击判定或启动 Python 映射进程。

| 机型 | 功能键单击（固定） | 可配置动作 | 电源键单击（固定） |
| --- | --- | --- | --- |
| U30 Pro | 下一页／唤醒屏幕 | 功能键双击、长按，电源键双击 | 亮灭屏幕 |
| F50 Pro | 无额外动作 | 功能键双击、长按 | 无独立电源键 |
| U30 Air | 唤醒指示灯 | 功能键双击、长按，电源键双击 | 唤醒指示灯 |
| V50 | 无额外动作 | 功能键双击、长按 | 无独立电源键 |

网页位于设备管理，可选无动作、切上网卡、开关 Wi-Fi、切 Wi-Fi 频段、切 NFC、自定义一行 shell 命令。
默认行为在选项中写明具体动作；U30 Air 功能键双击默认切频段、长按默认开关热点，其他可配置动作默认无动作。
电源长按始终由原 owner 处理关机／关机菜单，不允许映射。旧单击配置保留在用户文件但不再执行；旧页面尝试保存单击会收到明确拒绝。

只有配置了双击动作的按键才启用 250 毫秒窗口：第一次单击立即生效，第二次执行双击动作。
双击为“无动作”（或默认无动作）时，不进入双击识别，连续按多少次就响应多少次。
这意味着双击也会先发生一次固定单击动作，不以延迟单击换取双击排他。
U30 Pro 锁屏和关机菜单的原输入保护保留。

V50 原厂 key-function 使用 KEY_FN（464），U30 Air 使用 KEY_HELP（138），两款 Pro 使用 KEY_HOME（102）。
原厂 V50 设备树证据 SHA-256：9535e3560dadfee65e5fc9dfa4f3e574635f2d4da7402e940bf191c4e45eead6。
开关 Wi-Fi 使用 hotspot 后端选中的 AP 和保存状态，由该 owner 应用，不直接全局 wifi down。

## 快捷切卡的选择范围（2026-11-19）

U30 Pro、F50 Pro、V50 的“切换上网卡”按 SIM 管理页面的实体卡源列表循环，
从实际正在使用的卡源选下一项，末项回到首项。列表由各机型现有物理选卡 owner
按原机 board_id／手动产品形态提供，不把当前接入两个逻辑栈的卡源当成完整列表。
F50 Pro 的外置卡顺序与网页一致：外置 1（原始 ID 4）、外置 2（原始 ID 3）。

只有一个卡源时不重拨；状态未就绪或无法确认实际卡源时报错，不按旧保存值猜测。
切卡仍交给网页现有 data-sim apply 和各机型事务完成，保留互斥、eUICC 保护、
射频权限、AT owner 和切换回滚；实体卡 ID 不会直接传入逻辑 AT 卡槽选择。
U30 Air 维持两个逻辑槽位之间切换。可配置的双击、长按共用这一动作，不增加轮询。

## 事件与保存

启用双击时，窗口从第一次短按释放开始计时，250 毫秒内再短按才算双击；
第一次固定单击已经立即执行。未配置双击时不建立等待窗口。
电源长按直接沿原关机流程处理，并清除同键的双击历史。
计时仅存在于待判定的点击期间，没有新增轮询或第二个输入设备读取者。

自定义指令是一行 shell 命令，允许引号、管道、变量、重定向等 shell 语法，
以 root 身份在物理按键触发时执行。空命令、换行、NUL 不接受。
保存和读取设置均不执行命令；耗时动作在独立子进程中运行，不阻塞关机按键。

HTTP 保存会忽略 rpcd 附带的 `ubus_rpc_session` 传输字段，不将它作为按键选项保存；
其余未知设置（包括 power_long）仍拒绝。网页会显示具体保存错误并保留待重试的输入。
RPC 只开放 button_get / button_set；设置仍需要现有 LuCI 写权限。
按钮事件的 run / worker 入口没有发布为 RPC 方法。
内置动作沿原有选卡、Wi-Fi、NFC 所有者执行，不另开 AT 通道。
U30 Pro 保留锁屏、来电弹窗及电源菜单的输入保护。

设置沿用 unisoc_modem 或 u30pro_native_control 的用户配置，
固件代码放在 usr、opt、www 的镜像所属路径。
共享 LuCI root/htdocs、各机型 overlay 与 native runtime 构建路径负责完整交付；
新 backend 的 Python 文件也纳入交付文件检查，避免只更新网页。

## 离线验证

- 真实 HTTP/rpcd：四机型完整设置保存、新会话读回、UCI 落盘、无关选项保留、
  未登录和只读写入拒绝；可用 `tests/buttons_rpc_http.py --root <现有运行时>` 回归。
- 生产后端：四机型默认值、设置保存、shell 字符、单行校验、双击命令、
  电源长按禁止、旧 F50 Pro 设置保留，以及内置动作的原所有者调用。
- 生产按键代码：MU300 / F50 Pro 的 ucode 事件块，目标运行时完整编译；
  U30 Pro 原生模拟器验证无双击时连续按键不丢次数、250 毫秒边界、三击、关机长按、锁屏和原翻页。
- 浏览器：四机型、中文／英文／土耳其文、320 / 1280 像素，
  可见性、自定义字段、只读权限、保存失败和移动端溢出。
- 通过固定版本的真实差分生成器与执行器验证首次引入和后续更新，
  保留按键配置、Wi-Fi 配置及用户数据。

以上是离线验证，不表示已完成各机型的实际按键验收；本轮未部署到设备。
