# 实体按键自定义（Pro / MU300）

## 范围与默认动作

| 机型 | 功能键 | 电源键 |
| --- | --- | --- |
| F50 Pro | 短按、双击、长按；默认均无动作 | 不显示配置 |
| U30 Pro | 短按默认翻页；双击、长按默认无动作 | 短按默认唤醒／休眠；双击默认无动作 |
| U30 Air | 短按默认唤醒灯；双击默认切频段；长按默认开关热点 | 短按默认唤醒灯；双击默认无动作 |
| V50 | 短按、双击、长按；默认均无动作 | 不显示配置 |

网页位于设备管理。各动作可选择无动作、切换上网卡、切换 Wi-Fi 频段、
切换 NFC、自定义指令；另外保留默认行为和原 U30 Pro 的已有动作。
电源长按不进入自定义调度，继续保留现有的关机／电源菜单及硬件长按行为。

V50 按本机型原厂设备树的 key-function 使用 KEY_FN（464），U30 Air 使用
KEY_HELP（138），两款 Pro 使用 KEY_HOME（102）。
V50 证据为本地 v50-android.dts 的原厂 key-function 节点，
SHA-256：9535e3560dadfee65e5fc9dfa4f3e574635f2d4da7402e940bf191c4e45eead6。
该调查文件不作为构建输入；运行时仍用现有 mu300-device 区分硬件。

## 事件与保存

双击窗口为第一次短按释放后的 500 毫秒。在窗口内再次短按只发出一次双击，
不执行两次短按。单击在窗口结束后执行，三次连击按双击、单击处理。
电源长按直接沿原关机流程处理，并取消同键尚未提交的单击。
计时仅存在于待判定的点击期间，没有新增轮询或第二个输入设备读取者。

自定义指令是一行 shell 命令，允许引号、管道、变量、重定向等 shell 语法，
以 root 身份在物理按键触发时执行。空命令、换行、NUL 不接受。
保存和读取设置均不执行命令；耗时动作在独立子进程中运行，不阻塞关机按键。

RPC 只开放 button_get / button_set；设置仍需要现有 LuCI 写权限。
按钮事件的 run / worker 入口没有发布为 RPC 方法。
内置动作沿原有选卡、Wi-Fi、NFC 所有者执行，不另开 AT 通道。
U30 Pro 保留锁屏、来电弹窗及电源菜单的输入保护。

设置沿用 unisoc_modem 或 u30pro_native_control 的用户配置，
固件代码放在 usr、opt、www 的镜像所属路径。
共享 LuCI root/htdocs、各机型 overlay 与 native runtime 构建路径负责完整交付；
新 backend 的 Python 文件也纳入交付文件检查，避免只更新网页。

## 离线验证

- 生产后端：四机型默认值、设置保存、shell 字符、单行校验、双击命令、
  电源长按禁止、旧 F50 Pro 设置保留，以及内置动作的原所有者调用。
- 生产按键代码：MU300 / F50 Pro 的 ucode 事件块，目标运行时完整编译；
  U30 Pro 原生模拟器验证双击抑制单击、三击、关机长按、锁屏和原翻页。
- 浏览器：四机型、中文／英文／土耳其文、320 / 1280 像素，
  可见性、自定义字段、只读权限、保存失败和移动端溢出。
- 通过固定版本的真实差分生成器与执行器验证首次引入和后续更新，
  保留按键配置、Wi-Fi 配置及用户数据。

以上是离线验证，不表示已完成各机型的实际按键验收；本轮未部署到设备。
