# 看板 IMEI 与实际卡槽名称

IMEI1/IMEI2 始终表示基带的两个逻辑栈，不因物理选卡而交换号码。
括号内名称从实际 mux 路由取得：V50 显示内置 SIM1/2/3 或外置 SIM1，
按本机 board_id 验证该位置确实存在；其他没有 mux 的机型保留 SIM1/SIM2。
卡是否插入、射频是否开启，不改变其物理接线名称。

mu300-v50-sim status 的 logical_cards 给出两逻辑栈当前物理位置；它只读
现有 GPIO/UCI，不发 AT、不切卡。sim_get 把该信息带到网页，主页在原有
状态刷新周期内同步标签，不增加独立定时器；页面隐藏后沿用原有暂停行为。
未知板号或不可用的路由不猜测物理名称。读取失败清除网页旧的映射缓存。

只修改文字与只读状态输出；IMEI 读取/脱敏、上网卡标记、SPACTCARD、
卡槽切换事务、射频及 NV 行为均不变。中文、英文、土耳其文与两种主题
共用现有翻译/样式，长名称在移动端可换行，IMEI 数值保持完整。

Pro 仓库独立处理 MU3356/MU5358 的映射；E5 依用户要求不接入此更改。
