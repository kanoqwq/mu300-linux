# U30 Pro 屏幕频宽与电源菜单

## 频宽缺失

共享 cellparse 已把 NR 频宽解析为 nr.bw_mhz，把 LTE 频宽解析为 lte.bw。
原生信号页虽支持 nr_bw 和 LTE 单载波 bw_idx，但 MU300 屏幕 feed 遗漏了它们。

本次直接从同一份基带缓存投影 nr_bw 与 lte_bw；LTE 聚合不压成单一索引，
例如 20M+20M 显示为 20+20 MHz。旧第三方 feed 的 bw_idx 接口仍保留。
每次完整 feed 清理缺失频宽，防止切卡或切 RAT 后留着上次的带宽。
不新增 AT 命令、不改变卡槽、基带初始化和拨号所有权。

本机已授权热部署，当前 SIM1 NR 缓存频宽为 30 MHz。屏幕与 feed 已更新并
恢复运行，触摸／输入／feed 就绪；本轮 boot_id 和 modem_control PID 均未改变。
初次截图时仍在锁屏。后续仅在确认未启用 PIN 锁的情况下，通过正常软锁长按解锁，
获取真实信号页：n28、频宽 **30 MHz** 与共享缓存一致；截图完成后恢复锁屏。

## 电源菜单与图标

旧代码在 ui_key 中直接忽略非 HOME 的超长按键，电源键无法打开菜单。
现在 gpio-keys 的实际事件循环在按下达到 1500ms 时上报一次；松开不再次
触发短按动作。丢失事件清除长按状态，Wi-Fi 键配置保持原义。

菜单使用原生主题／磨砂背景／圆角卡片，关机、重启、取消均位于圆屏安全区；
选择动作后显示确认。菜单可覆盖锁屏，但不改变 PIN、锁定状态或底下页面。
取消恢复原界面；正在系统更新的不可交互 notice 不会被电源菜单抢占。
下拉栏电源图标也进入同一菜单，关机／重启通过本机 poweroff／reboot 正常执行。

重新拨号图标原箭头与圆弧端点及方向不一致；改为按圆弧末端的顺时针切线
生成箭头，不修改重新拨号的实际动作。

## 构建与回归

正式修改在 devices/u30pro/overlay 和 native/tools/ui，原始／本地来源哈希均记于
adaptations.json。原生屏幕重编，sources/finish 将二进制与脚本同步到正式 root。
未改内核，不需要重编内核。

新增回归直接执行生产 feed 的 LTE 分数带宽、聚合、NR、NSA 和未知值投影；
编译并运行原生 C 解码器。电源菜单回归编译真实 UI，覆盖短按、长按、暗屏、
PIN 锁屏、触摸滑动不误触、取消／返回、确认及更新 notice；真实 keys_read
以非阻塞输入管道模拟按住、重复、松开、SYN_DROPPED 和 HOME 长按。
所有关机／重启测试均为 host 模拟或替身命令，没有关闭实机或操作 NV。

当前电源菜单／箭头这轮的正式 root 一致性、目标 ELF、所有相关回归已通过。
图像检查已完成，菜单及确认页没有缺字、溢出或触点越界。
